# Céphalon — historical avatar product brief

<!-- impeccable:product-schema 1 -->

This records the visual-prototype phase. The current product is defined in the
root `PRODUCT.md`; the historical brief does not promise implemented desktop agents.

## Platform

Web.

## Stack

Three.js r182 and native JavaScript, Node.js 20+ HTTP server. The library and
fonts are served locally without installing dependencies to run the project.

## Users

The user observes and manipulates the avatar on a phone connected to the computer’s
local network.

## Product purpose

Represent a luminous intelligence within a damaged holographic crystal inspired
by Ordis from Warframe.

## Capabilities and constraints

The November 7, 2026 brief replaces earlier fragmentation, wave-orientation and
no-audio decisions. A coherent hexahedron replaces separated plates. Fragmentation
is a temporary reaction.

Three wave layers remain horizontal in XZ independently of crystal rotation. The
controller exposes states, emotions and separate microphone/output signals.
A clearly labeled simulated signal is available for the demo.

Rendering uses stylized glass, fractures, a volumetric core, emissive edges,
an HDR pipeline with selective bloom and local chromatic dispersion. Optical
controls isolate layers and adjust their parameters.

An approximately 40-second demo illustrates an agent receiving a request, thinking,
searching locally, discovering, analyzing, verifying and reporting to the Operator.
Mission text and voice are English only. Lines generated with the supplied model
follow phases, and the report states corresponding results. Work gestures remain
active during remarks; waves use actual voice levels. Pause suspends narration;
stop cuts it. Fictional data is labeled; filtering and analysis actually execute
in the browser. The scenario performs no web search, remote model call or action
on the Orbiter/computer.

Browser microphone access requires HTTPS or localhost. A local file, AudioNode
or conversation-system levels can drive output without microphone access.

English is the default voice language. Twelve original English lines are generated
offline through Piper and converted using the supplied Ordis RVC v2 model; twelve
French lines remain accessible. Four short game recordings sourced from WARFRAME
Wiki form a separate collection. The editor identifies provenance, offers playback
with actual audio analysis and MP3 downloads. Models and Python stay outside the
frontend build. This demo library is separate from on-demand STT/TTS.

The avatar is intended for reuse by an external general-purpose agent and future
open-source release. Declarative animation profiles bind reading, writing,
listening, speech, thinking, search, analysis, comparison, contact, summon and
report to configurable tools. Versioned JSON events track identified actions,
allow overlap and distinguish STT, TTS and subagent presence. Transport and real
agents belong to the integrating application. The editor supports preview,
variants and JSON import/export without changing rendering.

The crystal volume pulses with activity: concentration/release during summon,
thinking breaths and writing/presentation accents. A shared energy score
synchronizes faces, fractures, core, afterglow, XZ waves and links. Pulse and
radiance are per-profile settings. A 23-second showcase demonstrates sequences
without the mission panel, using a simulated signal only.

## Brand commitments

Ordis/Warframe reference. Original geometry without extracted game assets. Four
priority images and a fifth comparison image mentioned in the request were not
attached. Work follows the brief and an accessible official animated reference.

## Accessibility and inclusion

At the time of this historical brief, controls were French. Keyboard navigation,
44 px touch targets and reduced-motion support were included. Reduced motion
suppresses surprise jolts and flashes. Current project copy is English.
