# Résonance énergétique du Céphalon

`energy-showcase.webm` enregistre les 23 secondes de présentation en vue mobile 390 × 844 : repos, écoute, réflexion, écriture, summon, analyse et rapport. Les comportements sont les vrais profils réutilisables de l’avatar, avec un signal audio simulé et sans voix générée.

`showcase-review.json` relève la progression jusqu’à la fin, les facteurs d’échelle du cube et les rotations des anneaux. Aucune erreur JavaScript ou shader n’a été remontée. Les images `think-live.png`, `summon-live.png` et `report-live.png` viennent de cette séquence en cours de lecture.

`controls-review.json` observe la pause, la réduction du mouvement, l’import d’un ancien JSON v1 et la neutralisation des pulsations. `summon-desktop.png` inspecte la décharge à 1440 × 900. Les images numérotées et `visual-review.json` sont des études de charge / matière prises avant le dernier réglage de l’amplitude ; elles ne sont pas les captures de validation finale.

Aucun test unitaire n’a été ajouté ni exécuté. Le navigateur utilise WebGL logiciel ; le rendu sur téléphone réel reste à apprécier sur l’appareil de l’utilisateur.

Relancer : `http://192.168.129.101:5173/?showcase=1`. La pause et les interactions manuelles restent disponibles. Aucun vrai sous-agent n’est créé par cette présentation.
