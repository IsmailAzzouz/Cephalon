# Ordis — default draft profile

The profile currently represented in the playground: the name Ordis, a holographic
crystal, a tone inspired by the Warframe character and demo voice collections.
The proposed wake phrase for this profile is “Hey Ordis”.

Name, voice and style are not constraints of the Céphalon engine. Full profile
selection and customization are not implemented. Existing visual settings remain
available in the playground.
