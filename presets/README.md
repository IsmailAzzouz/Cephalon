# Companion profiles

Design boundary, without an implemented profile loader. Céphalon is the project;
the displayed name, wake phrase, voice, conversational tone and avatar style
belong to the selected profile.

`ordis/` describes this draft’s default profile. Another profile should reuse the
same conversation role, brain and specialists without changing their orchestration.
Separating profiles does not mean completely different renderers are supported yet.

Format, persistence and the customization interface remain to be defined.
