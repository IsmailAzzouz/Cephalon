# Conversation agent

To implement. Talks to the Operator: clarification, receiving requests, presenting
progress and returning results. Sends missions to the brain and relays its questions.
The avatar is this agent’s visual representation.

Ordis is the draft’s default profile, not a mandatory name for this role. Name,
wake phrase, voice, personality and visual style are intended to be customizable.
Profile configuration is not implemented yet. Role instructions and code will
live here; profiles are described separately in the root `presets/` directory.
