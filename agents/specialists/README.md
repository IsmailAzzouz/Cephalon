# Agents spécialisés

À implémenter. Chaque spécialiste reçoit du cerveau une mission délimitée,
le contexte utile et les capacités nécessaires. Il retourne un résultat étayé
ou un blocage au cerveau. Un spécialiste conduit une mission ; un outil exécute
une opération. Les premières spécialisations envisagées sont documentées ici.
